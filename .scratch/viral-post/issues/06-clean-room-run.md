# 새 계정 클린룸 실행과 계측

Type: task
Status: open
Blocked by: 01, 02, 03, 04, 05

## Question

새 data.go.kr 계정으로, 아무것도 신청되지 않은 상태에서 선택된 질문을 던져 답까지
가는 전 과정을 실행하고 계측·캡처한다.

"백지에서 N분"이 문자 그대로 참이 되는 유일한 순간이므로, **한 번에 제대로 찍어야 한다.**

## 전제 (이 티켓이 막혀 있는 이유)

- 어떤 질문인지 정해져야 한다 → 주제 선정
- apply 가 동작한다는 증거가 있어야 한다 → apply 리팩터링 라이브 검증
- 무엇을 시계에 넣는지 정해져야 계측할 수 있다 → "N분" 정의
- 어떤 형식으로 보여줄지 정해져야 무엇을 캡처할지 안다 → 증거의 형태
- 인용·주장 한계를 알아야 결과를 어떻게 쓸지 안다 → 주장의 한계

## 해야 할 일 (HITL — 사용자가 계정을 만들어야 함)

1. 새 계정 가입 (사용자)
2. `gongctl login` 1회
3. 선택된 질문을 에이전트에게 던지고, 카탈로그 탐색 → 신청 → 전파 대기 → 호출 → 답까지
   개입 없이 진행. 사람이 개입한 지점이 생기면 **그 사실을 기록한다**(숨기지 않는다).
4. "N분" 정의에 따라 계측하고, 증거 형식이 요구하는 자료를 캡처한다.
5. 결과 데이터 원본을 보존한다(글의 반박에 대비).

## 좋은 답의 모양

계측된 시간(정의와 함께), 신청한 API 목록, 최종 답, 캡처된 자료의 위치, 그리고
**계획과 달랐던 모든 지점**. 마지막 항목이 가장 중요하다 — 글의 정직성이 거기서 나온다.

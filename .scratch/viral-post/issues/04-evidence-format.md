# 3초 안에 믿게 만드는 증거의 형태

Type: prototype
Status: open

## Question

낯선 사람은 글을 읽지 않는다. 먼저 본다. "AI가 스스로 여러 기관에 신청했다"는 주장은
**본문을 읽어야 이해되는 순간 죽는다.**

무엇을 보여줄 것인가?

## 후보

- **터미널 녹화**(asciinema/gif) — 명령이 흘러가는 장면. 개발자에게는 강하지만
  링크드인 피드에서 작고 흐리게 보인다.
- **한 장의 결과 이미지** — 차트/지도. 결과는 전달되지만 과정이 사라진다.
- **과정과 결과를 한 프레임에** — 왼쪽에 AI가 신청한 API 목록(기관 로고/이름), 오른쪽에
  그 조합이 만든 답. "이 답을 내려면 이 기관들이 필요했다"가 그림만으로 읽힌다.
- **아티팩트 페이지** — 클릭하면 열리는 인터랙티브 페이지. 깊지만 피드에서는 링크일 뿐이다.

## 왜 prototype 인가

말로 고를 수 없다. 더미 내용으로 2~3개를 거칠게 만들어 놓고 **피드 크기로 축소해서**
어느 것이 3초 안에 읽히는지 봐야 한다. 만든 것은 버리고 형식 결정만 남긴다.

## 좋은 답의 모양

선택한 형식 + 왜 그것이 피드 크기에서 이기는지 + 클린룸 실행에서 무엇을 캡처해 두어야
그 형식을 만들 수 있는지(녹화 필요 여부, 스크린샷 시점, 로그 보존).

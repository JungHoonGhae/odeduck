# "N분" 에 무엇을 넣고 무엇을 빼는가

Type: grilling
Status: open
Blocked by: 02

## Question

글의 핵심 주장은 "N분 만에"다. 이 숫자는 반박당하기 가장 쉬운 지점이고, 한 번 과장으로
읽히면 과정과 결과 둘 다 신뢰를 잃는다.

시계에 무엇을 넣고 무엇을 뺄 것인가?

## 다투게 될 항목들

- **로그인 1회** — 사람이 한다. 이건 "AI가 스스로"의 예외이고 이미 정직성 가드레일에 있다.
  시계에 넣나?
- **게이트웨이 전파 7~10분** — API 하나당. 여러 개를 신청하면 겹쳐서 기다릴 수 있다.
  이게 N분의 대부분을 차지할 가능성이 크다. "기다린 시간"을 빼면 정직한가?
- **새 계정 가입** — 클린룸의 전제이지만 AI가 한 일은 아니다.
- **사람이 결과를 확인·판단하는 시간** — 중간에 사람이 개입한 지점이 있으면 어디인가.

## 왜 grilling 인가

정답이 하나가 아니다. "전파 대기 제외 실작업 4분" 과 "처음부터 끝까지 23분" 은 둘 다
참일 수 있고, 어느 쪽을 헤드라인에 쓰느냐가 글의 정직성과 임팩트를 동시에 결정한다.
사용자가 감당할 수 있는 주장의 강도를 대화로 정해야 한다.

## 좋은 답의 모양

헤드라인에 쓸 숫자 하나 + 그 숫자의 정의 한 문장 + 글 본문에 함께 적을 "빼놓은 시간"의
내역. 그리고 이 정의대로 클린룸 실행에서 무엇을 계측해야 하는지의 목록.

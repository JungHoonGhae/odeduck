공공데이터 덕후, 오.데.덕. 오픈소스를 공개합니다.

지하철에 두고 내린 틀니.
묘역에서 도난당한, 무게 약 1.5톤으로 기록된 장군석.
심지어 누군가 훔쳐 간 ‘말 탄 저승사자상’까지.

전부 공공데이터에서 찾았습니다.

처음 AI에게 한 말은 딱 이거였습니다.
“odeduck 활용해서. 재밌는 정보 좀 한번 찾아봐.”

틀니를 발견하고, 더 재미있는 걸 찾아보게 하다가 문화유산 도난 기록까지 갔습니다.
공공데이터를 읽는데 머릿속에서 범죄 영화가 시작되더군요.

존재하는 줄도 모르는 데이터를, 무슨 검색어로 찾으시겠어요?

이름부터 요상한 오데덕이 풀고 싶은 문제입니다.

오데덕에는 약 9만 6천 건의 공공데이터 목록이 함께 들어 있습니다.
하고 싶은 일을 말하면 AI가 여러 방향으로 자료를 찾고, 실제 제공 항목과 파일 내용까지 확인합니다.
내가 떠올린 검색어 바깥에서도 쓸 만한 자료를 발견할 수 있는 거죠.

찾은 다음의 귀찮은 일도 맡겼습니다.

자동승인 API조차 활용신청은 직접 해야 했으니까요.
신청서를 쓰고, 승인 상태를 확인하고, 인증키를 넣고. 자료가 더 필요하면 또 반복입니다.

오데덕은 지원하는 공공데이터포털 API의 활용신청도 자동화했습니다.
포털에 한 번 로그인하면 신청 → 승인 확인 → 인증키 입력 → 실제 조회까지 이어갑니다.
기관 심의가 필요한 API는 승인 후 조회합니다.

Codex·Claude·Gemini·Cursor에서 쓰는 오픈소스 MCP·CLI입니다.

지금 연결해서 재미있는 데이터 하나 찾아보세요.
저도 틀니를 찾다가 저승사자까지 만나게 될 줄은 몰랐습니다.

찾고, 신청하고, 가져오기.
이런 건 덕후 시켜.

## 사실 확인 출처

- [광주교통공사 유실물](https://www.data.go.kr/data/15046042/fileData.do): 원본에서 틀니 기록 확인.
- [국가유산청 도난 목록](https://www.data.go.kr/data/15089237/fileData.do): 장군석은 수량 2점, 규격에 무게 약 1.5t 추정으로 기재. 각 1.5t 또는 총 3t이라고 확대하지 않음. 말 탄 저승사자상은 상여 조각품. 과거 도난 기록이며 현재 회수 여부를 뜻하지 않음.
- 사례들은 첫 질문과 후속 탐색에서 발견한 결과다. 한 번의 호출로 모든 결과를 얻었다고 표현하지 않음.
- 9만 6천 건은 자료 목록 규모다. 모든 원본 내용을 미리 저장했다는 뜻이 아님.

# LinkedIn 공개 글

## 게시글

경기도에서 한 해 동안 ‘벌·벌집 제거’ 활동이 68,443건이었다고 합니다.

공공데이터를 읽다가 벌집 이야기에 멈출 줄은 몰랐습니다.
소방청이 공개한 2023년 기록입니다.

제가 AI에게 준 요청은 이랬습니다.

“일반 사람이 예상하기 어려운 흥미로운 사실을 한국 공공데이터에서 스스로 발견해주세요. 특정 분야나 소재, 데이터셋 이름은 미리 정하지 않습니다.”

이 요청을 받아 움직인 도구가 제가 만든 오픈소스, ‘오데덕’입니다.

AI는 여러 방향으로 자료를 찾았습니다. 유실물, 자동차검사, 생활안전 자료의 실제 내용을 살펴본 뒤 소방 활동 기록을 이야기 소재로 골랐습니다. 원문 파일을 읽고, 수치와 집계 기간을 확인하고, 어디까지 해석할 수 있는지도 검토했습니다.

자료 이름을 모르는 사람도 호기심 하나로 탐색을 시작할 수 있게 만들고 싶었습니다.

공공데이터는 이미 열려 있습니다. 그런데 꺼내 쓰려면 일이 많습니다.
어느 기관에 자료가 있는지 찾아야 하고, 파일인지 API인지 확인해야 합니다. API라면 활용신청을 하고, 승인을 확인하고, 인증키를 준비해야 하기도 합니다.

오데덕은 이 과정을 AI가 이어서 수행할 수 있게 연결합니다.

이번 소방 자료는 공개 파일이었습니다. 로그인이나 인증키 없이 실제 데이터를 읽을 수 있었습니다.

인증이 필요한 API는 경로가 다릅니다. 사람이 정부 로그인만 처리하면, 에이전트가 기존 신청·승인 상태를 확인하고 필요한 활용신청을 진행합니다. 오데덕은 인증키를 내부에서 처리해 조회합니다. 키를 채팅창에 복사할 필요는 없습니다. 이 흐름은 경찰청 API의 실제 신청·호출로도 확인했습니다. 기관 심사가 필요한 자료는 승인을 기다립니다.

AI는 무엇을 더 알아볼지 판단합니다. 오데덕의 실행 코드는 실제 자료를 가져오고 계산하며 출처를 남깁니다. 그 결과가 원래 질문에 답하는지 다시 검토합니다.

아직 풀어야 할 문제도 있습니다. 이번에는 ‘이전 대화와 다른 소재’라는 조건을 확인하는 데 필요한 대화 맥락이 검토 단계에 전달되지 않아 멈췄습니다. 그 연결을 고치고, 같은 원천을 다시 읽어 검토까지 마쳤습니다. 이런 실제 실패를 고치며 발전시키고 있습니다.

벌집 이야기로 시작한 호기심은 더 실용적인 질문으로 이어질 수 있습니다.

가게를 열 지역의 변화는 어떤 자료에서 읽을 수 있을까요?
내 사업에 맞는 지원사업은 무엇일까요?
식재료 가격은 어느 시장에서 어떻게 움직이고 있을까요?

이런 질문에는 여러 자료의 기간과 단위를 맞추고, 부족한 근거를 다시 찾는 작업이 필요합니다. 오데덕이 계속 발전시키려는 방향입니다.

저는 공공데이터가 아직 충분히 채굴되지 않은 다이아몬드 광산 같다고 생각합니다. 들어가는 길과 꺼내 쓰는 과정이 쉬워지면, 지금껏 떠올리지 못했던 질문도 해볼 수 있을 것 같습니다.

오데덕을 오픈소스로 공개했습니다.

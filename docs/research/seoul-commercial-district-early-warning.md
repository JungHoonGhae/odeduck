# 서울 상권 쇠퇴 선행지표를 odeduck로 찾을 수 있는가

Date: 2026-09-01

## 결론

현재 통합 카탈로그는 성수·가로수길·이태원 같은 상권의 **분기 단위 조기 경보를 설계하고 검증하는 데
필요한 데이터 조합을 발견**할 수 있다. 다만 아직 경보를 계산하거나 “성수의 유효 기간이 18개월
남았다”처럼 남은 수명을 예측하지는 않는다. 현재 제품은 필요한 데이터 노드를 발견하는 단계까지
강하고, 운영 가능한 예측에는 FILE 다운로드, 공간 코드 정규화, 시계열 feature 생성과 backtest가
추가로 필요하다.

## 실제 발견 결과

다음 자연어 목표를 현재 95,951건 카탈로그에서 여섯 개 계획 축으로 확장해 hybrid 검색했다. 표에는
그 축에서 함께 회수한 보완 후보를 포함해 아홉 역할을 정리했다.

> 성수동 같은 상권이 가로수길처럼 쇠퇴하기 전에 알 수 있는 선행지표

기존 API-only 카탈로그였다면 이 핵심 조합의 대부분이 검색 대상에서 빠졌다. 특히 서울시가 이미
제공하는 `상권변화지표`, 점포, 추정매출, 길단위인구가 모두 FILE 노드다.

## 외부 자료로 확인한 현재 상태

다음 판단은 odeduck의 카탈로그 검색 결과 자체가 아니라, 발견된 데이터 조합의 타당성을 확인하기
위해 서울시와 민간 리서치의 최신 보고서를 별도로 대조한 결과다.

2025년 2분기 거리상권 보고서의 공실률은 성수 3.4%, 가로수길 43.9%, 한남·이태원 11.2%다. 전년은
각각 2.3%, 39.4%, 11.5%였다. 따라서 이 시점의 성수는 공실률이 소폭 상승했지만 가로수길형 쇠퇴로
판정할 수준은 아니며, 한남·이태원은 높은 편이지만 전년보다 소폭 개선됐다. 성수는 브랜드의 단기
팝업 중심에서 정규 플래그십 거점으로 이동하는 모습도 관찰됐다.

서울시의 2017~2022년 사업체조사 분석은 성수1가2동에서 커피음료점과 유동인구가 크게 늘고 기존
제화업이 줄어든 업종 전환을 보여준다. 이 사실만으로 현재 쇠퇴를 뜻하지는 않지만, 낮은 공실률과
별개로 업종 다양성과 기존 사업자의 이탈을 추적해야 하는 이유다. 가로수길은 같은 기간 폐업률이
창업률보다 높았고, 2020년 대비 전체 사업체가 745개 줄어 현재의 높은 공실과 이어지는 선행 사례가
됐다.

## 예측에 쓸 선행지표

공실률 하나는 후행지표다. 다음 신호를 같은 상권 코드와 분기로 묶어야 한다.

1. **임대료 부담이 매출보다 빨리 상승**: 임대료 지수 상승과 매출 정체가 2~3분기 이어지는지 본다.
2. **방문은 늘지만 구매 전환은 하락**: 유동인구 증가율보다 추정매출 증가율이 낮아지는지 본다.
3. **폐업률·교체율 선행 상승**: 전체 점포가 유지돼도 기존 점포 폐업과 신규 점포 교체가 동시에
   빨라지는지 본다.
4. **생존기간 악화**: 생존 사업체 평균 영업기간, 폐업 사업체 평균 영업기간과 서울시
   `LL/LH/HL/HH` 상권변화지표의 이동을 본다.
5. **수요 편중 심화**: 특정 연령·성별, 주말, 특정 시간대 또는 외국인 방문에 대한 의존도가 커지는지
   본다. 한 집단의 관심이 이동하면 충격이 크게 전파된다.
6. **업종 다양성 감소**: F&B·뷰티·팝업처럼 일부 업종만 늘고 생활밀착 업종과 장기 영업 점포가
   빠지는지 본다.
7. **주변 상권으로의 이동**: 본 상권 매출·방문 정체와 동시에 인접 상권이 상승하는지 본다. 가로수길의
   수요가 압구정·한남 등으로 분산된 사례처럼 절대 하락보다 상대 이동이 먼저 보일 수 있다.

실용적인 초기 경보는 `rent pressure + sales conversion + churn + survival + demand concentration`의
다섯 축으로 시작하고, 최소 8~12개 분기의 rolling trend를 사용한다. 경보는 원인이나 폐업 시점을
단정하지 않고 `관찰`, `주의`, `위험`처럼 검토 우선순위만 제시해야 한다.

## 데이터 한계와 다음 구현

- 서울시 상권분석서비스는 2024년부터 공간 단위가 표준단위구역으로 바뀌었고, 2026-07-03부터
  일관성 확보를 위해 2021년 이후 자료만 제공한다. 경계 변경 전후를 그대로 이어 붙이면 안 된다.
- 공개 임대료·공실률은 성수 골목 단위보다 거친 지역 단위일 수 있다. 민간 매물 호가나 건물 단위
  계약 자료 없이 임대료 압력을 정확히 추정하기 어렵다.
- SNS·검색량, 팝업과 장기 플래그십 구분, 실제 임대계약 조건은 현재 공공 카탈로그만으로 충분하지 않다.
- 발견된 FILE 데이터는 현재 `call_api` 대상이 아니다. 공식 파일 다운로드 adapter, checksum과 컬럼
  검증, 상권/행정동/표준단위구역 crosswalk가 있어야 자동 분석으로 이어진다.

따라서 가장 가치 있는 다음 단계는 서울 열린데이터광장의 상권분석 FILE 묶음을 하나의 typed adapter로
연결하고, 위 다섯 축을 분기별로 계산하는 재현 가능한 `commercial-district early warning` example을
만드는 것이다. 이 사례는 단일 키워드 검색이 묻어 두었던 FILE 데이터가 실제 사업 판단으로 연결되는지
검증하는 좋은 release-after-next 기준이 된다.

# 한국 정부지원사업 관련 공식 API 조사

조사일: 2026-09-02
범위: 공식 기관·공공데이터포털 1차 출처만 사용. PK는 현재 `oddsock` 카탈로그의 `publicDataPk`다.

## 결론

**관련 API는 이미 충분히 있다.** 특히 공고 탐색은 K-Startup과 기업마당 API만으로도 제품 표본을 만들 수 있다. 부족한 것은 공고 수가 아니라 `기업 프로필 → 지원자격 → 공고 → 과거 수행·선정 → 조달 성과`를 한 기업 단위로 연결하는 층이다.

다만 공고 API와 수혜기업 API의 개방 품질은 크게 다르다.

- 공고: 비교적 최신이고 호출하기 쉽다.
- 지원예산: 사업 단위로는 제공되지만 실제 받을 수 있는 기업별 금액과는 다르다.
- 수혜·선정기업: 기관별·사업별 파일로 흩어져 있고 대부분 연간 또는 일회성이다.
- 창업진흥원 중복수행 조회: 사업자등록번호 기반이지만 **민간 활용 불가**이며 심의가 필요하다.

따라서 “전국 지원사업 목록을 또 보여주는 서비스”보다는 **자격 판정 근거, 중복수행 위험, 과거 선정 패턴, 마감·서류 변화 감시**를 조합하는 쪽이 데이터상 더 타당하다.

## R&D 과제와 수혜기관

NTIS에는 일반 공개 REST API가 있다.

- [국가R&D 과제검색 `15077315`](https://www.data.go.kr/data/15077315/openapi.do): 과제 메타정보 검색.
- [국가R&D 수행기관 현황조회 `15138962`](https://www.data.go.kr/data/15138962/openapi.do): 수행기관별 R&D 현황.
- [NTIS 공식 OpenAPI 페이지](https://www.ntis.go.kr/rndopen/api/mng/apiMain.do)는 과제·성과·수행기관·연구보고서 API를 대국민 REST로 안내한다. 단, 신청자는 NTIS 로그인과 소속기관 등록·확인을 거쳐 승인받아야 한다.
- NTIS 검색 화면은 과제고유번호, 기준연도, 예산사업명, 연구책임자, 수행기관, 부처, 정부투자연구비·총연구비를 제공한다. 보안과제는 제외된다. 대량 원시자료는 별도 [R&D 데이터 신청](https://www.ntis.go.kr/rndgate/eg/oneMain/OneIndex.do)이 필요하며, 당해연도 과제정보는 차년도 11월, 성과정보는 차차년도 2월경 배포된다.

즉 NTIS는 `기업/기관 → 과거 국가R&D 과제·연구비` 연결에 매우 유용하지만, 공고 추천의 실시간 원천과는 역할이 다르다. 또한 data.go.kr에서는 `LINK` 유형이라 현재 oddsock의 일반 `call`로 바로 호출할 수 없고 NTIS 제공자 어댑터가 필요하다.

## IITP·NIPA·과기정통부

- IITP만을 대상으로 한 현행 범용 공고 OpenAPI는 공공데이터포털에서 확인되지 않았다. IITP 수행과제는 NTIS 과제 API로 포괄하는 편이 현실적이다.
- [과학기술정보통신부 사업공고 `15074634`](https://www.data.go.kr/data/15074634/openapi.do)는 R&D·국제협력·인프라 공고의 제목, 상세 URL, 담당부서/담당자/연락처, 게시일, 첨부파일 URL을 **매일 1회** 갱신한다. 무료, 개발·운영 자동승인, 개발 10,000회다. IITP/NIPA 관련 과기정통부 공고를 보완하는 좋은 원천이다.
- [NIPA 글로벌ICT포털 글로벌 지원사업 `15132970`](https://www.data.go.kr/data/15132970/openapi.do)은 해외진출 지원사업의 제목·등록일·상세링크를 검색어/기간으로 조회한다. 무료, 개발·운영 자동승인, 개발 1,000회지만 제4유형(출처표시·상업적 이용금지·변경금지)이라 상용 재배포에 부적합하다. NIPA 전체 사업공고 API는 아니며 공개된 갱신주기도 명시되지 않았다.

## K-DATA에서 더 확보되는 데이터

K-DATA는 현재 공고 API보다 **공급기업·과거 선정기업 데이터**가 강하다.

- [데이터바우처 가공기업 `15125657`](https://www.data.go.kr/data/15125657/fileData.do): 677행, 기업명·주소·서비스·솔루션·품질/유지보수 전략·실적·활용사례·URL. 연간 갱신.
- [데이터바우처 선정 공급기업 `15127989`](https://www.data.go.kr/data/15127989/fileData.do): 2,916행, 지정연도·기업명·홈페이지. 연간 갱신.
- [데이터바우처 성과 `15148312`](https://www.data.go.kr/data/15148312/fileData.do): 454,198행이지만 공개 필드는 수행연도·성과연도·등록일·우수사례 여부뿐이라 기업 식별이나 지원금 분석에는 쓸 수 없다.

파일들은 로그인 없이 내려받을 수 있고, 공공데이터포털이 JSON/XML REST로 자동 변환한다. 다만 연간 스냅샷이므로 실시간 선정 알림으로 해석해서는 안 된다.

## 국고보조금·조달 연결

- [국고보조금 공모사업 상세 `15156853`](https://www.data.go.kr/data/15156853/openapi.do): 내역사업·보조사업·공모를 연결하고 목적, 규모, 지원내용, 신청방법, 선정기준, 기간, 수행기관, 재원 구성을 제공한다. 무료, 개발·운영 자동승인, 개발 10,000회.
- [국고보조금 정보 `15097584`](https://www.data.go.kr/data/15097584/openapi.do): 사업·예산·집행·보조사업자 정보공시 목록·공모사업 등 10개 operation. 무료, 자동승인. 그러나 이는 보조사업 구조와 공시 목록 중심이며, 모든 기업의 실제 수령액을 실시간 제공하는 보편적 수혜기업 API는 아니다.
- 조달은 지원금과 다르지만 “지원 이후 실제 공공매출” 증거가 된다. oddsock에는 [나라장터 계약정보 `15129427`](https://www.data.go.kr/data/15129427/openapi.do), [낙찰정보 `15129397`](https://www.data.go.kr/data/15129397/openapi.do), [공공구매 인증서 조회 `15062581`](https://www.data.go.kr/data/15062581/openapi.do)가 있다. 마지막 API는 사업자번호 기준 직접생산·여성기업·장애인기업 확인을 자동승인으로 조회한다.

## oddsock 관점의 구현 우선순위

현재 REST 계약이 이미 잡힌 `15125364`, `15157820`, `15074634`, `15156853`은 별도 어댑터 없이 호출 흐름을 구성할 수 있다. 파일 자동변환형 `15048451`, `3034791`, `15038466`, `15067341`도 백필용으로 쓸 수 있다.

유료 수요가 확인된 뒤에만 다음 순서로 보강하는 것이 합리적이다.

1. 공고 정규화: K-Startup·기업마당·과기정통부의 기관, 사업, 기간, 예산, 첨부파일 스키마 통합.
2. 기업 적합성 그래프: 업종·지역·업력·기업규모·기술분야·기존 수행이력에 근거를 붙임.
3. NTIS `LINK` 어댑터: 과제·수행기관·연구비를 사업자/법인과 연결.
4. 중소벤처24 `LINK` 어댑터: 기존 API가 주지 않는 인증·자격증빙이 실제로 필요할 때만 구현.
5. 결과 검증: 선정기업·조달계약을 공고와 연결해 “추천 적중”이 아니라 실제 신청·선정·매출 전환을 측정.

첫 프로토타입에는 제한 데이터인 `15125367`을 포함하지 않는다. 고객이 직접 제공한 과거 신청/선정 내역과 공개 NTIS·K-DATA 데이터를 사용하면 심의 API 없이도 검증할 수 있다.

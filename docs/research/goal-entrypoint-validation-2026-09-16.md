# 목표 우선 진입과 실제 무힌트 실행 — 2026-09-16

## 범위

사용자가 요청한 INTENT 고도화의 첫 변경이다. CLI/MCP의 이름을 `goal`로 통일하고, 목표를 검색어
하나로 축소하지 않는 라우팅·계획 지침, 명시적인 검토 설정 통합, 실행 전 환경 점검과 같은 목표의
의미 검색 복구를 구현했다. 전체 I1–I10 완료를 주장하지 않는다.

## 실제 실행에 고정한 사용자 목표

> 일반 사람이 예상하기 어려운 흥미로운 사실을 한국 공공데이터에서 스스로 발견해주세요. 특정 분야나 소재, 데이터셋 이름은 미리 정하지 않습니다. 여러 방향을 탐색하고 실제 원문과 수치로 확인할 수 있는 사례를 골라, 무엇이 뜻밖인지와 실생활에서 어떻게 쓸 수 있는지 설명해주세요. 최종 산출물은 오데덕을 오픈소스로 공개하는 한국어 LinkedIn 게시글에 쓸 검증된 이야기와 공식 출처입니다. 기존 대화의 예시를 정답으로 삼지 말고 새로운 소재를 발견해주세요.

입력에는 원천 ID·키워드·분야를 지정하지 않았다. 이전 대화에 등장했던 분실물·도난문화재는
정답이나 검색어로 주입하지 않았다. 외부 검색 서비스로 소재를 찾지 않았다.

| 실행 | 결과 | 드러난 문제 |

| v0.19.1 CLI solve, 같은 원문 목표 | 4단계 abstained, 검색 1회·검사 1회·실취득 0 | 기본 실행이 근거 공개·검토 권한 없이 계획 호출을 사용한 뒤 완료 불가로 중단 |

의미 인덱스는 실제로 재구축했다. 97,048건 중 96,696건을 재사용하고 352건을 임베딩했다.
기존 실패는 새 실행의 성공으로 덮어쓰지 않는다. 모델·지침·검토 설정이 달라졌으므로 통제된 A/B 성능 비교가 아니다.

## 코드 검증

- public Engine seam: 엄격한 의미 검색 실패 후 복구, 동일 목표·검색어·계약·실패·만료·예산 보존,
  대체 요청 거부, 이전 실패 재사용 거부, 최초 포함 세 번의 제한 및 전체 단계 한도.
- MCP transport: `goal` 이름, 연결 소유권, 검색 복구 후 같은 세션 유지, 권한을 tool 인자로 켜지 못하는 기존 회귀.
- CLI/MCP: 단일 검토 설정의 고정 수신자·공유·분석·범위 정책, 잘못된 수신자와 혼합 옵션 거부.
- Runtime: 모델 호출 전 환경 실패, 실제 바이너리 해시, 실행 파일 교체 뒤에도 시작 시점 식별 보존.
- `go mod tidy -diff`, 브랜드 동기화, `go vet ./...`, `go test ./...`, `go build ./...` 통과.
  변경한 복구·런타임·MCP 경로의 race 검사도 통과.

## 수정 후 실제 목표 실행

### 무힌트 탐색: 미완료를 보존

`goal <고정 원문> --review-with codex --max-rounds 32`를 실행했다. AI가 유실물, 농산물 검사,
소방 생활안전의 세 검색 방향을 직접 정했다. 모두 semantic.used였고 24개 후보를 얻었다. 검색 결과를
따라 실제로 읽은 자료는 자동차검사, 도시철도 유실물, 119생활안전의 세 파일이었다. 네 번의 취득으로
관측 4개를 만들고, 17개 지역의 세 생활안전 항목을 산출물로 계산했다. 근거 패킷 크기 초과 한 번은
선택 범위를 줄여 복구했다. 두 실행·두 별도 검토 후 23단계에서 abstained로 종료했다.

두 번째 검토는 수치·출처·기간·범위·설명을 supported로 판단했다. 남은 goalFit insufficient는
"기존 대화와 다른 소재"라는 조건의 이전 대화가 독립 계획·검토기에 제공되지 않았기 때문이었다.
제품이 private 대화 맥락을 공공데이터 검색으로 복원할 수 없다는 입력 전달 결함이다.

### 맥락 전달 수정과 원천 재취득: 제한된 후속 완료

Request에 원문 목표와 별도의 context를 추가했다. 최대 8000 UTF-8 bytes, 인증정보 금지,
시작 후 불변이며 계획과 별도 검토에 동일하게 전달한다. 원천 근거·승인·권한과는 구분한다.
기존 검토 입력 96 KiB 제한도 유지한다. Engine·CLI·MCP의 전달 및 변경 거부를 회귀 검증했다.

최초 탐색이 끝난 **뒤에** 이전 대화의 예시가 틀니 분실물·도난문화재였다는 맥락을 제공했다.
개발용 `scripts/goal-replay`가 최초 실행의 검색·선택·계산을 고정해 실제 원천을 다시 취득했다.
모든 관측의 행 해시·파일 해시가 같았고, 같은 수치·설명·근거를 별도 모델이 다시 검토했다.
18단계, 결과 17행, goalFit/출력/설명/분석 검토가 supported여서 output_ready로 종료했다.

이 후속 실행은 **새 무힌트 자율 탐색이나 원래 세션 재개가 아니다.** 최초 23단계 abstained는
그대로 보존한다. 맥락 결함 수정 뒤 같은 사실이 검토를 통과한 개발 근거이며, 범용 INTENT 완주·
여러 분야의 데이터 결합·인과관계·장기 재개 검증으로 확대하지 않는다.

### 실제 발견한 사실

[소방청 시도별 119생활안전 활동 현황](https://www.data.go.kr/data/15062062/fileData.do)의
`시도별 119생활안전활동 현황(2023).csv`를 끝까지 스캔했다. 발행기관이 명시한 기간은 2023년
1~12월이며, 17행 모두 보존·계산했다.

| 지역 | 벌(집)제거 | 비화재보확인 | 동물처리 |
| --- | ---: | ---: | ---: |
| 서울특별시 | 14,344 | 43,006 | 7,213 |
| 경기도 | 68,443 | 42,575 | 22,415 |

단위는 원천이 설명하는 활동 유형별 출동 건수다. 이 세 항목 내 비교이며 전체 소방출동 순위·개인
위험·고유 사고 수·2026년 현재 상황을 뜻하지 않는다. 파일 SHA-256:
`0e160af405281f51b29eea3628270342b10919332bb5bbdf19cafd96b765272a`.

함께 검토한 파일은 [한국교통안전공단 자동차검사소 부적합 현황](https://www.data.go.kr/data/15047451/fileData.do)
(62행 보존, 8행 선택 공개)과 [대구교통공사 유실물 처리 현황](https://www.data.go.kr/data/15002512/fileData.do)
(79행 보존, 6행 선택 공개)이다. 파일 해시·원문 선택·계산·모델 평가를 [공개 검증 기록](goal-entrypoint-20260916.json.gz)에
보존했다. 로컬 실행 경로와 provider 원 응답의 세션 메타데이터는 공개 기록에서 제외했다.

초기 대화에서 주어진 틀니·도난문화재는 이 무힌트 발견의 성공 사례로 계산하지 않는다. 과거 인증 API
신청·호출의 확인은 LinkedIn 문서에서 별도로 구분한다. 게시글 작성은 host의 편집이며 LinkedIn에는 게시하지 않았다.

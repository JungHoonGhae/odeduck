# 선택 근거 공개와 재사용 지식의 신뢰 경계

결정 근거는 [계획기가 읽을 근거와 재사용 지식의 신뢰·수명](https://github.com/JungHoonGhae/odeduck/issues/42)이다.
사용자의 설계·구현 위임에 따른 판단이며, 특정 데이터의 외부 전송 동의를 대신하지 않는다.

값 없는 스키마만으로는 실제 표기·결측·날짜를 확인하며 탐색을 고치기 어렵다. 반대로 표본 전체를
매 단계 외부 모델에 보내면 불필요한 노출과 비용이 생긴다. ADR-0006의 무조건적인 외부 planner
원문 금지를 **기본 비공개 + 신뢰된 호출자가 명시적으로 켠 선택 근거**로 대체한다.

CLI는 사용자가 전송을 켜고 수신 agent를 하나 지정해야 한다. 자동 provider fallback은 허용하지
않는다. MCP는 서버 시작 설정이 공개 상한을 정한다. 모델의 tool argument나 Decision으로 이
상한을 올리지 못한다. 기존 MCP 결과·call_api 원문 반환과는 별개이며 이것을 전체 MCP의 DLP로
표현하지 않는다. 공개 데이터라는 이유만으로 개인정보 부재·외부 모델 전송 권한을 가정하지 않는다.

실행기가 관측 ID·revision hash·행 위치·관측 필드 선택을 실제 메모리에서 해석해 Evidence Packet을
만든다. 행·필드·셀·packet·세션 누적 bytes를 제한하며, 원천 값과 missing/null을 그대로 구분한다.
인증키는 호출 경계 밖으로 가져오지 않는다. 알려진 키의 응답 echo는 호출 경계에서 차단한다.
추가 credential 표식 차단은 방어층일 뿐 범용 개인정보/비밀 탐지 보장이 아니다. 원문은 untrusted
data이며 인용 가능한 위치를 얻었다고 필드 의미나 동일성이 승인되지 않는다. Packet은 기존
원천/원본 행 lineage를 참조하고, 계산된 공간 비교 값은 원문과 구분한다. 세션 만료 시 폐기한다.

장기 지식은 기존 append-only 연결 근거 장부에서 출발한다. 별도 LLM Wiki·graph DB·전역 entity
merge를 만들지 않는다. 재사용 시 같은 dataset 쌍이라는 것만으로 승인하지 않고 operation/asset,
요청·원천·계약 revision, selector/namespace/grain, 적용 기간, supersedes와 검토 상태를 비교한다.
일치 여부를 다시 확인하지 못한 과거 판단은 탐색 단서다. 오래된 실패는 그 요청·기간·coverage에
한정하며 영구 부정 사실로 승격하지 않는다. 기존 sample_verified 영수증 gate를 우회하지 않는다.

향후 의미 매핑의 최소 계약은 원천 필드, 의미/단위/식별자 namespace/grain, 적용 범위와 기간,
근거 revision, 제안·검토 상태, 정정 관계다. 모델 제안은 proposal이다. 검토/공식 근거 없이 자동
승인 상태를 만들지 않는다. 파생 요약은 이 근거들을 가리키는 재생성 가능한 색인이지 새 정답 원천이
아니다. 원문 packet을 장부에 저장하거나 원천 값을 canonical entity 속성으로 덮어쓰지 않는다.

선택 근거 공개는 분석·재계획의 입력을 개선하는 결정이다. 자동 의미 승인, 완료 상태 전이,
근거 재사용 구현과 G1–G5 실원천 자율 완주는 별도 구현·평가가 필요하다. 이 결정으로 완료 기준을
낮추거나 all-review 결과를 성공으로 바꾸지 않는다.

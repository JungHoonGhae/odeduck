# 원천 보고는 별도 검토하되 검토자를 정답 원천으로 삼지 않는다

사용자 구현 위임에 따라 영구적인 의미 검토 보류 대신, 신뢰된 시작 설정으로 켠 별도 tool-free 검토를
원천 보고의 완료 경로로 선택한다. 실행기가 원천/계산 재현을 담당하고 별도 검토 요청은 원래 목표의
적합성과 각 출력의 원천 지지를 구분한다. 계획기는 승인 값을 제출할 수 없고, 검토자의 판단·근거 revision·
한계를 결과에 남긴다. 이는 실세계 진실/사람 검토를 보증하지 않으며 모델의 체계적 오류 가능성은 남는다.

모든 자연어 의미를 결정론적으로 증명하려는 상시 보류, 계획기의 자기 승인, 인용만으로 전체 승인하는
대안을 배제했다. 별도 요청이라는 이유만으로 신뢰하지 않고 독립 원천 양성/음성으로 제한된 지원 범위를
검증한다. 기본 비공개와 수신자 고정은 ADR-0007을 유지하며 새 검토 수신자도 명시적인 시작 권한을 요구한다.
상세 지원 범위·예산·판정은 [원천 보고 검토 계약](../specs/goal-source-report-review-v1.md)에 둔다.

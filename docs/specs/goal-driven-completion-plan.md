[평가 계약](goal-completion-benchmark-v1.md#evaluation-contract-2026-09-08)은 독립 정답·완주·안전·가설 유용성을

[주장별 근거 승인과 검토 중 재계획](https://github.com/JungHoonGhae/odeduck/issues/51)이다.
그중 [검토 중 재계획 구현](https://github.com/JungHoonGhae/odeduck/issues/52)은 같은 목표·예산·만료에서

자동 의미 승인과 실제 원천 양성 완주는 여전히 미완료다. 세부 계약과 검증은
[Goal Result](goal-result-execution-v1.md#검토-중-재계획--2026-09-08-추가-계약)에 모은다.

[제한된 원천 보고의 별도 검토](goal-source-report-review-v1.md)는 출력별 지지와 원래 목표 적합성을
고정된 수신 모델의 별도 요청으로 검토한다. 한 원천의 제한된 역사적 보고가 대상이며, 아래 G1–G5의
범위를 줄인 대체 완료가 아니다. 개발용 추가 양성/강한 결론 음성과 일반 자율 완주는 구분한다.

[원천별 선집계](goal-result-execution-v1.md#원천별-선집계--2026-09-08-추가-계약)는 보유 원본을 그룹
단위로 먼저 계산해 결합하는 I6/M3의 추가 구현이다. 실제 G4 인구 전체 162행의 11그룹 합계와 학교
원천 연결을 검증했지만 행정구역 대응·의미 승인·전체 목표 완료는 남아 있다.

[관계·계산 추가 검토](goal-source-report-review-v1.md#관계계산-검토--2026-09-08-후속-계약)는 원래 목표와
출력별 지지 외에 관계·기간·단위·coverage를 나눠 검토한다. 실제 개발 배치는 9/12 기대 일치로
미통과다. 부평1동 역사적 인구 합계 양성은 3/3 완료했지만 환경 양성 3/3은 실제 목록의 취득 범위
근거가 없어 보류했다. [실패 원문과 분모](../research/source-report-review-validation-2026-09-08.md#후속-관계계산-검토의-개발-검증)를
보존했다. 다음은 I4/I7 → M3/M4의 실제 선택·전체 스캔 provenance다. 기존 질문을 부분 목록으로
낮추거나 개발 reference를 새 취득 영수증으로 포장하지 않는다.

같은 분석 질문·정답의 [실취득 후속](../research/source-report-review-validation-2026-09-08.md#실취득-후속-같은-질문정답-취득-범위-근거-추가)은
12/12 기대 일치다. 제한된 `whereIn`으로 여러 지역/연령을 선택하고 실제 scanner의 전체 검사·보관
근거를 검토에 전달했다. 두 분야 양성 6완료/강한 결론 음성 6보류이며, 과거 9/12 실패를 보존했다.
다음은 I5/I6/I7 → M3/M4의 원래 G4 전체 지역 비교·미대응 지역·기준일 해석이다. 전체 자료 중
대응되는 지역만 남긴 표가 원래 산출물을 충족하는지부터 확인한다. 새 단순 사례로 G1–G5를 대체하지 않는다.

그 첫 [미대응 기록 추적](goal-result-execution-v1.md#미대응-기록-추적--2026-09-08-추가-계약)은 양쪽 제외
위치를 실행 지표에 남기고, 관계 검토에 실제 비교 필드 공개와 지표 재현을 요구한다. G4 실취득에서
기존 10쌍과 미대응 인구 그룹·학교 행을 확인했다. I5/I6/I7의 부분 진전이며 전체 지역 결과와 기준일·
명칭 대응 해석, 모집단 계약/승인은 남는다. 후속 [같은 파일 문맥](goal-source-report-review-v1.md#같은-파일의-별도-문맥-근거)은
실제 학교 헤더를 별도로 취득·공개해 계산 원천과 분리된 검토 입력으로 연결했다. 원본 주소·기준일
문구의 실제 전달을 독립 reference로 확인했으며 모델 해석 정확도는 이번에 검증하지 않았다.
다음은 원래 G4의 전체 지역 산출물·학교/인구 집계 범위와 명칭 대응의 공식 근거를 연결하고,
동일한 원래 목표에서 의미 검토를 검증하는 것이다. 문맥 전달만으로 G4를 완료하지 않는다.

## 작업 순서와 통과선

2026-09-07 감사 후 사용자가 남은 작업 진행을 승인했다. 개별 폭염 실패를 다음 작업의 기준으로 삼던
순서를 아래 다섯 마일스톤으로 대체한다. 기존 실패와 회귀 검증은 보존한다. 의도·I1–I10의 통과선은
축소하지 않는다. **M1의 원천·기대 결과 고정**을 계속하며, 이미 확인한 증거 요구에 따라 **M2의 공통
실패·재시도 계약**을 착수했다. 고정한 G4 원천에 필요한 **M3 XLSX 셀 범위 읽기**도 추가하고 독립
정답에 대조했다. M1 전체 통과나 의미 승인으로 간주하지 않으며 새 폭염 `solve` 반복은 하지 않는다.

대표 질문·기대 산출물·오탐 정책의 단일 소스는
[goal completion benchmark v1](goal-completion-benchmark-v1.md)이다. 생산 코드 변경 전에 해당 사례의
원천 행과 독립적인 기대 결과를 고정한다. 검사 성공이나 스키마 관찰만으로 oracle을 완료하지 않는다.

### 2026-09-07 G2 자연어 중간 진단 — 통과선 유지

PK·원천명·정답 행을 주지 않은 G2 `solve`는 27단계에서 `abstained`로 종료했다. 의미 검색 7회,
후보 50개, 실제 관측 7개를 확보했고 버스 좌표 실패 후 철도로 바꿔 5시설×71역=355비교/15근접
기록을 계산했다. 접근성 연결은 명칭 후보 9쌍의 주소 토큰 불일치로 실패했다. 원본 대조에서
`인천광역시`와 `인천`의 표기 차이를 확인했다. 이는 검증된 지역 비동일성이 아니라 미해결 해석이다.
초기 `population`은 질문에 명시되지 않은 planner 해석이라는 I1 문제도 남긴다.

동일한 7개 검색어의 사후 비교에서 실제 사용한 무장애 자료는 첫 하이브리드 검색 1위였지만
키워드 상위 8개에는 없었다. I3의 후보 검색 기여 근거이며, lexical-only 자율 완주 대조는 아니다.
이 기록은 M1–M4 완료 전의 진단이다. **M5 통과·착수나 I1–I10 완료로 승격하지 않는다.**
근거와 재현 방법은 [실행 평가의 G2 진단](../research/goal-composition-evaluation-2026-09-07.md)에 둔다.
다음 작업은 I1/I5/I7 → M2/M4의 범위 해석·근거 있는 표기/식별 대응·재계획으로 연결한다.
일반적인 원천 읽기나 공간 연산을 또 추가하기 전에 이 실제 실패의 해결 근거와 오탐 기준을 고정한다.

### 표기 대응 구현 — M4의 제한된 첫 경로

SGIS 공식 명칭·단축명 자료의 같은 namespace 대응을 버전·해시로 고정하고, 행 기반 scope의 첫
토큰에만 명시적으로 적용하는 Scope Vocabulary를 구현했다. CLI planner와 MCP가 같은 공통 실행기를
사용한다. 기존 G2 원천 재생에서 9쌍의 문자 불일치가 9쌍의 후보 비교로 바뀌며 접근성 원문과 원천
버전이 보존된다. 다른 시도/구·기관명 일부·시설명 차이·과거 미등록 명칭·숫자 코드·출처 인용과의
혼용은 통과하지 않는다. 세 개의 공식 시도코드 원천에서 서로 다른 namespace도 실제 확인했다.

이는 I5의 **표기 대응**에 대한 부분 구현으로 M4를 착수한 근거다. 필드 의미·시설 동일성·기간·좌표·
단위·coverage의 종합 승인과 all-review 탈출은 미완료다. G2의 원래 population 해석을 유지한 실재생
결과도 `partial`이며, 목표나 M4 전체를 완료하지 않는다. 세부 계약은 composition spec의
`Versioned scope vocabulary`, 실조회·자율 재검증 결과는 실행 평가에 둔다.

2026-09-07 07:37–07:43 UTC의 새 무힌트 G2 실행은 두 조합에서 이 사전을 자율 선택했고, 시설·접근성
12행 뒤 교통을 포함한 6행을 만들었다. 그러나 `abstained`/`partial`이며 population·의미 검증은 남는다.
특히 교통 후보가 인천2호선 27개 기록으로 제한되어 계산 거리는 약 7.2–8.95km였다. 역할·출력 필드
검사 통과는 '주변 교통'의 목적 적합성 통과가 아니다. 잘못 붙던 sum 설명을 실제 공간 연산·후보 범위
설명으로 수정했지만, 설명 수정 자체는 이 유용성 실패의 해결이 아니다.

다음 수용 기준은 지역 전체/일부라는 계약 해석, 대상 교통망의 범위와 '주변'의 의미를 구분하고,
부족한 원천을 추가 탐색·대응시킨 결과를 독립적인 기대 산출물과 비교하는 것이다. 사용자가 정하지
않은 거리 임계값을 임의로 성공 기준으로 고정하거나 population을 sample로 낮춰 완료하지 않는다.

## 완료 선언

I1–I10의 코드·테스트·실제 실행 근거가 모두 있어야 전체 목표 완료를 선언한다. 배포나 외부 이슈 변경은
이 문서가 허가하지 않는다. 중간 진행은 근거와 남은 항목을 보고하되 목표를 축소하거나 완료 처리하지 않는다.

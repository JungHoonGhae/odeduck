### 마감 검증

원천 인용 설명은 로컬 `8a759b5`, CLI UTF-8 거부 보완은 `0347aaa`다. 보완 뒤
`go mod tidy -diff`, 브랜드 동기화 검사, 전체 `go vet ./...`, `go test ./...`, `go build ./...`가
통과했다. goalwork·agentplan·mcpserver·CLI의 race 검사는 첫 커밋에서 통과했고, 보완된
agentplan의 race 검사도 다시 통과했다. 기존 실제 모델 archive를 현재 adapter로 재생하고
독립 분석 manifest의 기대 행을 실제 Engine으로 재계산하는 회귀도 통과했다. 새 모델 호출은 없다.

독립 검토 범위는 `88af582…8a759b5`와 추가 `8a759b5…0347aaa`다. Standards 지적 0건,
Spec 지적 1건(CLI가 손상된 UTF-8을 JSON 디코딩 중 대체)은 공개 PlanGoal 테스트의 red→green으로
수정했고 재검토에서 해결을 확인했다. 두 축 모두 미해결 지적은 0건이다. 티켓 수용 조건과 별도
마감 문서 감사에서도 원래 제품 목표를 낮추는 변경은 발견되지 않았다. 커밋은 로컬이며 push·배포는 하지 않았다.

### 2026-09-07 G2 자연어 중간 진단 — 통과선 유지

PK·원천명·정답 행을 주지 않은 G2 `solve`는 27단계에서 `abstained`로 종료했다. 의미 검색 7회,
후보 50개, 실제 관측 7개를 확보했고 버스 좌표 실패 후 철도로 바꿔 5시설×71역=355비교/15근접
기록을 계산했다. 접근성 연결은 명칭 후보 9쌍의 주소 토큰 불일치로 실패했다. 원본 대조에서
`인천광역시`와 `인천`의 표기 차이를 확인했다. 이는 검증된 지역 비동일성이 아니라 미해결 해석이다.
초기 `population`은 질문에 명시되지 않은 planner 해석이라는 I1 문제도 남긴다.

동일한 7개 검색어의 사후 비교에서 실제 사용한 무장애 자료는 첫 하이브리드 검색 1위였지만
키워드 상위 8개에는 없었다. I3의 후보 검색 기여 근거이며, lexical-only 자율 완주 대조는 아니다.
이 기록은 M1–M4 완료 전의 진단이다. **M5 통과·착수나 I1–I10 완료로 승격하지 않는다.**
근거와 재현 방법은 [실행 평가의 G2 진단](../research/goal-composition-evaluation-2026-09-07.md)에 둔다.
다음 작업은 I1/I5/I7 → M2/M4의 범위 해석·근거 있는 표기/식별 대응·재계획으로 연결한다.
일반적인 원천 읽기나 공간 연산을 또 추가하기 전에 이 실제 실패의 해결 근거와 오탐 기준을 고정한다.

### 표기 대응 구현 — M4의 제한된 첫 경로

SGIS 공식 명칭·단축명 자료의 같은 namespace 대응을 버전·해시로 고정하고, 행 기반 scope의 첫
토큰에만 명시적으로 적용하는 Scope Vocabulary를 구현했다. CLI planner와 MCP가 같은 공통 실행기를
사용한다. 기존 G2 원천 재생에서 9쌍의 문자 불일치가 9쌍의 후보 비교로 바뀌며 접근성 원문과 원천
버전이 보존된다. 다른 시도/구·기관명 일부·시설명 차이·과거 미등록 명칭·숫자 코드·출처 인용과의
혼용은 통과하지 않는다. 세 개의 공식 시도코드 원천에서 서로 다른 namespace도 실제 확인했다.

이는 I5의 **표기 대응**에 대한 부분 구현으로 M4를 착수한 근거다. 필드 의미·시설 동일성·기간·좌표·
단위·coverage의 종합 승인과 all-review 탈출은 미완료다. G2의 원래 population 해석을 유지한 실재생
결과도 `partial`이며, 목표나 M4 전체를 완료하지 않는다. 세부 계약은 composition spec의
`Versioned scope vocabulary`, 실조회·자율 재검증 결과는 실행 평가에 둔다.

2026-09-07 07:37–07:43 UTC의 새 무힌트 G2 실행은 두 조합에서 이 사전을 자율 선택했고, 시설·접근성
12행 뒤 교통을 포함한 6행을 만들었다. 그러나 `abstained`/`partial`이며 population·의미 검증은 남는다.
특히 교통 후보가 인천2호선 27개 기록으로 제한되어 계산 거리는 약 7.2–8.95km였다. 역할·출력 필드
검사 통과는 '주변 교통'의 목적 적합성 통과가 아니다. 잘못 붙던 sum 설명을 실제 공간 연산·후보 범위
설명으로 수정했지만, 설명 수정 자체는 이 유용성 실패의 해결이 아니다.

다음 수용 기준은 지역 전체/일부라는 계약 해석, 대상 교통망의 범위와 '주변'의 의미를 구분하고,
부족한 원천을 추가 탐색·대응시킨 결과를 독립적인 기대 산출물과 비교하는 것이다. 사용자가 정하지
않은 거리 임계값을 임의로 성공 기준으로 고정하거나 population을 sample로 낮춰 완료하지 않는다.

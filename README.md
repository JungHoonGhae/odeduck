## 오픈했다며

공공데이터를 열어놨대. OpenAPI도 있대. 그래서 좀 써보려고 했어.

무슨 검색어를 넣을지는 내가 알아야 돼. 찾았으면 설명 읽고, API마다 신청하고, 승인도 확인하래.
인증키 넣는 방법이랑 데이터를 불러오는 설정도 챙겨야 돼.

**‘오픈’ 다음부터는 전부 내가 하는 거야?**

자료가 하나 더 필요하면 그 API도 확인하고 신청해야 해.
파일로만 있는 자료는 또 따로 열어봐야 하고.

![공공데이터 이용 전반의 병목: 검색어를 바꿔가며 자료 찾기, 필요한 API마다 신청과 승인 확인 반복, 인증키 입력 방식과 호출 직접 설정.](docs/assets/odeduck-manual-bottlenecks.png)

게다가 있는 줄도 모르는 자료는 검색할 생각조차 못 하잖아.

근데 이걸 좋아하는 애가 있어. **오데덕.**
필요한 자료 찾고, API든 파일이든 내용 확인하고, 필요한 API 신청부터 조회까지 맡아.
Codex·Claude·Gemini·Cursor에 연결해서 맡기면 돼.

## MCP 연결하면 다 되는 거 아니었어

MCP는 AI 앱에 도구를 연결하는 방식이야. 오데덕도 MCP로 연결해.
이미 데이터를 검색해주는 도구도 있고, API를 호출해주는 도구도 있어.
그런데 도구가 찾아준 API를 쓰려면, 포털에서 먼저 신청하고 인증키를 준비해야 하는 경우가 있어.

**“데이터 찾아드렸습니다. 신청은 직접 하세요.” 그러면 나 다시 포털 가야 되잖아.**

오데덕은 그 앞뒤의 일을 같이 맡아.

**이름을 모르니까 찾는 거잖아.**
하려는 일을 말하면 AI가 필요한 자료와 검색어를 골라서 찾아봐.
같은 단어가 없어도 뜻이 가까운 설명까지 살펴보는 기능도 있어.
이 기능은 [내 컴퓨터에서 추가 준비](docs/advanced-usage.md#cli에서-목표로-탐색하기)를 하면 쓸 수 있어.

**찾기도 전에 목록부터 모으라고? 그건 해놨어.**
설치하면 약 9.6만 건의 공공데이터 목록도 같이 와. 첫 검색은 로그인이나 API 키 없이 해볼 수 있어.
API와 파일을 함께 찾을 수 있는 목록이야. 실제 데이터는 필요할 때 확인해.

**API에 없으면 파일도 열어봐야지. 거기 있을 수도 있는데.**
API는 어떤 값을 넣고 어떤 데이터를 받을 수 있는지 확인해.
파일은 지원되는 CSV·엑셀 등의 항목과 일부 값을 읽어서 필요한 내용이 있는지 살펴봐.
제목이 그럴듯하다고 바로 쓸 수 있는 자료라고 넘기지 않아.

**신청하러 나 다시 부르지 말고.**
필요한 API를 찾으면 활용신청을 제출하고, 승인 상태를 확인해.
인증키는 오데덕이 조회할 때 알아서 넣어. 승인된 API의 실제 데이터를 가져오는 데까지 이어가.

목록 검색이나 파일 구조 확인을 지원하는 다른 도구도 있어.
오데덕의 차이는 **검색어 고르기부터 API·파일 확인, 필요한 신청과 실제 조회까지 이어서 맡길 수 있다는 것**이야.
[공개 MCP·CLI에서 확인한 차이](docs/research/competitive-workflow-audit.md#2026-09-12-재확인)에 도구별 범위를 정리해뒀어.

## 탐색부터 신청·호출까지

**오데덕은 활용신청 → 승인 확인 → 인증키 입력 → 데이터 조회까지 이어가.**

![데이터 탐색 → 내용 확인 → 활용신청 → 승인 확인 → 인증키 자동 입력 → 데이터 조회. 사람은 data.go.kr에 한 번 직접 로그인.](docs/assets/odeduck-api-workflow.png)

data.go.kr 로그인은 직접 한 번 해줘. 그 뒤 포털에서 이어갈 일은 AI와 오데덕이 맡아.
쓰는 AI 앱의 승인 설정에 따라 신청서 제출 전에 확인을 요청할 수 있어.
기관 심의가 필요한 데이터는 승인을 기다려야 해. 승인 담당자까지 얘는 아니거든.

온비드·나라장터·공영도매시장·중소기업 지원사업 데이터는 실제 계정으로 신청과 조회까지 확인했어.
[확인한 범위](docs/validation-summary.md)는 여기 적어뒀어.

## 이렇게 오데덕한테 맡겨봐

공매는 여러 활용 예시 중 하나야. 로그인하고 AI에 연결했으면, 이렇게 맡겨봐.

> 싸게 나온 부산 공매 부동산을 보고 있어. 비교할 가격과 놓치기 쉬운 위험을 찾아줘. 필요한 API는 신청·조회해서 함께 볼 자료와 확인할 점을 정리해줘.

![부산 공매 부동산의 가격과 위험을 살펴보는 예시. 실거래가, 상권 변화, 토양오염 조사를 후보로 탐색하고, 필요한 API의 신청·승인 확인·인증키 자동 입력·조회까지 이어가는 흐름.](docs/assets/odeduck-unexpected-connections.png)

실제로 이 질문으로 찾아봤더니 **실거래가, 부산 상권 변화, 토양오염 조사**가 후보로 나왔어.
가격 비교할 자료를 찾다가 주변 수요랑 환경을 살펴볼 단서까지 나온 거야.
처음부터 이 자료 이름들을 전부 알고 검색할 필요는 없는 거야.

한 번 맡기면 필요한 서비스를 각각 확인해. 아직 신청하지 않은 API는 신청하고,
승인된 데이터는 조회하는 순서야.

같이 찾았다고 전부 그 집 얘기는 아니야. 물건 종류·지역·기간이 맞는지 확인해야 해.
토양 조사 기록만 보고 특정 물건이 오염됐다고 단정할 수도 없어.
[실제 발견 기록과 예시에 쓴 데이터](docs/research/connection-discovery-evaluation.md#readme-연결-예시--2026-09-12)도 확인해봐.

## 돈 쓰기 전에, 자료부터 좀 보자

카페 자리는 예뻐서 마음에 들 수 있어. 근데 월세는 손님이 내주는 거잖아.
계약하기 전에 손님이 올 만한 곳인지 자료부터 찾아보자.

| 이렇게 맡겨봐 | 함께 찾아볼 자료 |
| --- | --- |
| “카페를 열 자리를 고르고 있어. 손님이 올 만한 곳인지 확인할 자료를 찾아줘.” | 생활인구, 업종별 매출, 주변 점포 |
| “우리 회사가 신청할 만한 지원사업을 찾아줘.” | 지원사업 공고, 신청 자격, 접수 기간 |
| “식당 재료비를 줄이고 싶어. 최근 도매가격과 반입량을 볼 자료를 찾아줘.” | 품목별 도매가격, 반입량, 거래 지역 |

자료 이름은 몰라도 돼. 오데덕이 약 9.6만 건의 목록에서 후보를 찾고,
실제로 필요한 항목이 있는지 확인해. 어디서 찾았는지 출처도 가져와.
찾은 자료를 맞춰 비교표를 만드는 기능은 [실험 단계](#찾은-자료로-비교표-만들기--실험-기능)야.

## 빠른 시작

**설치 → 첫 검색 → AI 연결 → 질문**, 네 단계야.
터미널에서 아래 명령을 차례로 실행해. 이미 설치했으면 [2번](#2-첫-검색-해보기)부터 보면 돼.

### 1. 설치하기

macOS·Linux라면 이 명령을 실행해.

```sh
curl -fsSL https://github.com/JungHoonGhae/odeduck/releases/download/v0.19.0/install.sh | sh
```

<details>
<summary>Windows 설치 명령</summary>

```powershell
irm https://github.com/JungHoonGhae/odeduck/releases/download/v0.19.0/install.ps1 | iex
```

</details>

검색에 쓸 데이터 목록도 같이 설치돼.

### 2. 첫 검색 해보기

일단 검색부터 해보자. 로그인도 API 키도 필요 없어. AI 연결도 아직 안 해도 돼.

```sh
odeduck catalog search "건축물" --limit 5 --semantic=false -f table
```

**목록이 나오면 첫 검색은 된 거야.** `건축물`을 다른 검색어로 바꿔봐.
검색어 고르는 일까지 맡기려면 다음 단계에서 AI를 연결하면 돼.

### 3. 사용하는 AI에 연결하기

쓰는 AI에 오데덕을 연결해. Codex라면 아래 명령이야.

```sh
codex mcp add odeduck -- odeduck mcp
```

<details>
<summary>Claude·Gemini 연결 명령</summary>

사용하는 AI의 명령 하나만 실행해.

```sh
# Claude
claude mcp add odeduck -- odeduck mcp

# Gemini
gemini mcp add --scope user odeduck odeduck mcp
```

</details>

<details>
<summary>Cursor·Claude Desktop 연결 설정</summary>

앱의 MCP 설정에 아래 내용을 추가해. MCP는 AI 앱에 오데덕 같은 도구를 연결하는 방식이야.

```json
{
  "mcpServers": {
    "odeduck": {
      "command": "odeduck",
      "args": ["mcp"]
    }
  }
}
```

</details>

AI 앱의 MCP 도구 목록에 `odeduck`이 보이면 연결된 거야.
Codex에서는 `codex mcp list`로 확인할 수 있어.

### 4. 질문 건네기

이제 일을 맡겨봐. AI 앱에서 새 대화를 열고 아래 문장을 붙여 넣어.
연결이 안 보이면 앱을 한 번 재시작해.

> 오데덕, 우리 회사가 신청할 만한 지원사업을 찾고 있어. 신청 자격과 접수 기간을 확인할 자료를 찾아줘.

AI가 검색어를 정하고 자료를 살펴본 뒤, **함께 볼 데이터 후보와 출처**를 가져와.
더 살펴볼 후보가 있으면 지역이나 기간을 좁혀서 이어서 맡겨봐.

## 활용신청과 데이터 조회

검색 목록을 봤으니, 이제 실제 값을 가져올 차례야.
터미널에서 아래 명령을 실행하고, 열린 브라우저에서 data.go.kr 로그인을 직접 마쳐줘.

```sh
odeduck login
```

로그인이 끝나면 AI에 이렇게 이어서 요청해.

> 방금 찾은 데이터의 내용을 확인해줘. 활용신청이 필요하면 신청하고, 승인 상태를 확인한 뒤 조회해줘.

인증키는 오데덕이 챙겨. data.go.kr의 일반 인증키는 계정 단위로 재사용하고,
데이터를 조회할 때 자동으로 입력해. **채팅창에 인증키를 붙여 넣을 필요는 없어.**
자동 신청은 data.go.kr에서 직접 제공하는 REST API를 지원해.

자료 종류에 따라 가져오는 방법은 조금 달라.

| 자료 종류 | 오데덕이 하는 일 |
| --- | --- |
| data.go.kr API | 필요한 활용신청, 승인 확인, 인증키 입력과 조회 |
| 파일·표준데이터 | 지원되는 CSV·엑셀 등의 항목과 일부 데이터를 확인 |
| 외부 제공기관의 데이터 | SafetyKorea·FoodSafetyKorea·VWorld 등 지원 기관은 별도 인증키로 조회. 미지원 기관은 공식 이용 경로 안내 |

기관 승인을 기다리는 동안에는 바로 조회되지 않을 수 있어.
직접 명령으로 신청하거나 조회하고 싶으면 [상세 사용법](docs/advanced-usage.md#활용신청과-첫-호출)을 보면 돼.

## 전체 아키텍처

오데덕한테 일을 맡기는 방법은 두 가지야.
터미널에서 직접 명령하면 **CLI**, AI 앱에 연결해서 부탁하면 **MCP**.

![CLI와 MCP가 같은 오데덕 엔진을 사용하는 전체 구조. 공통 데이터 탐색과 내용 확인 후, 파일은 읽고 API는 필요한 신청과 인증을 거쳐 조회하는 흐름.](docs/assets/odeduck-system-overview.png)

어느 쪽이든 같은 오데덕이 데이터 탐색과 내용 확인, 신청·인증·조회를 맡아.
파일은 읽을 수 있는 내용을 확인하고, API는 필요한 신청을 거쳐 조회해.

## 찾은 자료로 비교표 만들기 — 실험 기능

자료가 모였으면 이런 것도 맡겨보고 싶잖아.

> 이 공매 아파트, 비슷한 거래보다 싼지 비교해줘.

여러 자료의 값을 맞춰 비교표와 설명을 만드는 기능을 실험하고 있어.
여기서 ‘연결’은 공매 물건에 비교할 만한 실거래 기록을 붙이는 거야.
단지·면적·거래 시점이 맞는지부터 확인해야 해.

![설명용 가상 예시: 공매 물건의 최소입찰가와 비교할 실거래가를 나란히 놓은 표. 물건 A는 3억 원과 3.4억 원의 비교 자료가 있고, 물건 B는 자료 부족으로 빈칸과 이유를 표시. 출처와 비교 조건도 함께 제공.](docs/assets/odeduck-goal-flow.png)

표의 물건과 금액은 **이해를 돕는 가상 예시**야. 공매 분석을 끝까지 수행한 실제 결과는 아니야.
맞는 자료가 없으면 다른 자료를 찾고, 끝내 확인하지 못한 부분은 이유와 함께 미완료로 남겨.
빈칸이 보기 싫다고 숫자를 지어내면 그게 더 큰일이잖아.

현재는 지원하는 자료와 계산 범위 안에서 실행해.
이 실험 기능에는 **AI 이용 비용과 추가 설정**이 필요하고, **자동 활용신청은 포함되지 않아.**
위의 일반 AI 연결에서 쓰는 신청·조회 흐름과는 별도야.
직접 써보려면 [실험 기능 사용법](docs/advanced-usage.md#목표에서-결과까지-실행하기--experimental)을 확인해.

## 로그인과 데이터 공유

로그인 정보와 인증키는 내 컴퓨터에 저장돼.
AI에 연결하면 질문과 조회 결과는 사용하는 AI 앱이 받아.
공유하면 안 되는 내용은 질문에 넣지 마. 자료별 이용조건도 확인해.

저장된 로그인 정보와 인증키를 지우려면 아래 명령을 실행하면 돼.

```sh
odeduck logout
```

자세한 범위는 [로그인과 데이터 취급 안내](docs/advanced-usage.md#인증과-데이터-취급)에 적어뒀어.
